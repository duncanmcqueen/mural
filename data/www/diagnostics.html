Servo / pen

Hobby servos give no feedback: these are the commanded values, not the measured horn position. If the horn is visibly not where it's told to be, or it buzzes/shudders while holding, it's probably straining against the slot or binding.

Servo settings

Limits are hard stops in firmware: nothing (calibration, drawing, tests) can command the servo outside them. Set them just inside the range where the horn moves freely. Slower speed = less current spike per move.

System

Adds a "Starting the move to x, y" line per drawing command. Off by default: each line holds up the motors for a few milliseconds, which adds up over a drawing, and it quickly pushes older entries out of the log.

Lets you watch progress, read the log and pause or stop a drawing. The web server runs on the other CPU core from the drawing loop, so it shouldn't affect motion. If you notice stutters or blobs while a page is open, turn this off: the web UI then goes offline while drawing, as in the original firmware.
